в файле test_order_page.py описан  тест  test_create_order.py  для проверки заказа по кнопкам заказать вверху и внизу страницы
в файле  test_redirect_page.py описаны тесты для проверки  test_redirect_logo_scooter - перехода на тестовый сайт тренажера если кликнуть на логотип самоката 
и тест test_redirect_yandex_logo для проверки, что если клинуть на логотип яндекса на страницы, то будет переход на страницу Яндекса
в файле test_main_page.py находится тест test_question_and_answer для провреки ответов на вопросы 


в файле main_page_locators.py находится описание локаторов для основной страницы
в файле order_page_locators.py находится описание локаторов для страницы заказов самоката
в файле redirect_page_locators.py находится описание локаторов для страницы Яндекса для проверки редиректа при нажатии на логотип яндекса

в файле base_page.py описаны базовые методы, которые прменяются  на любой страницы сайта 
в файле main_page.py находятся методы для работы с главной страницы сайта
в файле order_page.py находятся методы для работы со станицей заказа самоката
в файле redirect_page.py находятся методы для проверки редиректа по станицам
